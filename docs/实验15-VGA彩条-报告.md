# 实验十五 VGA 彩条方格显示

## 一、实验目的

掌握 VGA 行场时序；理解 RGB 接口与扫描原理；实现彩条与方格图案。

## 二、实验原理

VGA 逐行扫描，显示器接收 RGB 模拟信号、行同步 HS、场同步 VS。640×480@60Hz 的标准像素时钟为 25.175 MHz，行周期 800 像素、场周期 525 行。

时序（负极性同步）：

| 项目 | 数值 |
|---|---|
| 行周期 | 800 时钟 |
| 行同步 | 656–751（低有效） |
| 场周期 | 525 行 |
| 场同步 | 490–491（低有效） |
| 图像区 | 640×480 |

## 三、设计与实现

四种模式，全部由逻辑实时生成，不占 ROM，KEYA 循环切换：

- 模式 0：八条竖彩条，每条 80 像素（灰、黄、青、绿、品红、红、蓝、深灰）。
- 模式 1：八条横彩条，每条 60 行，颜色顺序同上。
- 模式 2：80×60 棋盘，异或配色（黑底白格）。
- 模式 3：80×60 棋盘，同或配色（白底黑格）。
- 颜色用组合函数直接产生，不建数组，避免初值不入 RAM 的问题。

时钟：48 MHz 二分频得 24 MHz 作像素时钟。因 24 MHz 略低于标准 25.175 MHz，刷新约 56 Hz，绝大多数显示器可接受。讲义使用 ALTPLL 产生 25 MHz；本实现未使用 PLL，属等效简化。

## 四、管脚分配

| 信号 | 管脚 | 信号 | 管脚 |

## 五、编译结果

map / fit / asm 全部通过，0 error；生成 `vga_smpte.sof`（281,522 字节）。

## 六、仿真验证

模式 0 抽点校验颜色（每 80 像素一条）：

```
h=50  v=100 -> 10010010   灰
h=120 v=100 -> 11111100   黄
h=200 v=100 -> 00011111   青
h=400 v=100 -> 11100000   红
h=600 v=100 -> 01001001   深灰
```

KEYA 每按一次进一档（按 30ms 以上才采得到），0→1→2→3→0 循环；按四次回到模式 0，颜色序列复现。

## 七、结论

行场时序正确，四种模式按 KEYA 循环切换，竖/横彩条与两种棋盘均按设计输出；颜色由组合逻辑直接产生，不依赖存储器初值。

## 八、DIY 说明

在讲义四模式基础上，彩条颜色自选为灰、黄、青、绿、品红、红、蓝、深灰，棋盘格大小取 80×60。
## 九、KEYA 四模式（P1 补齐）

KEYA（PIN_124，低有效）消抖后循环切换四种模式：竖彩条（8 条各 80 像素）、横彩条（8 条各 60 行）、异或棋盘（80×60 格）、同或棋盘。报告前述彩条为模式 0。
