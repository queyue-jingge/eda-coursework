# 实验二 计数器

## 一、实验目的

1. 掌握 Quartus II 的硬件描述语言设计方法。
2. 理解同步计数器原理。
3. 设计带使能、进位输出与同步清零的增 1 四位 N（N<16）进制同步计数器。

## 二、实验原理

同步计数器所有触发器共用同一时钟，上升沿触发。计数值到 N−1 后，下一个时钟沿回到 0，同时进位输出有效一个周期。

清零方式取同步清零：清零信号有效时，计数器不立即复位，等下一个时钟沿才归零。

## 三、设计与实现

采用参数化模块，N 与位宽可配：

```verilog
module cntN #(parameter N = 10, parameter W = 4) (
    input clk, input clr, input en,
    output reg [W-1:0] q, output carry
);
  assign carry = en && (q == N-1);
  always @(posedge clk) begin
    if (clr) q <= {W{1'b0}};
    else if (en) begin
      if (q == N-1) q <= {W{1'b0}};
      else q <= q + 1'b1;
    end
  end
endmodule
```

顶层 `cnt4` 取 N=10，即十进制 0–9 循环；改 N 即可得任意 N 进制。

## 四、管脚分配

| 信号 | 管脚 |
|---|---|
| CLK | PIN_121 |
| Q3 | PIN_50 |
| Q2 | PIN_53 |
| Q1 | PIN_54 |
| Q0 | PIN_55 |
补充：clr=PIN_122，en=PIN_124，carry=PIN_7（已锁定，非自动分配）。

## 五、编译结果

map / fit / asm 全部通过，0 error；生成 `cnt4.sof`（281,522 字节）。

## 六、仿真验证

ModelSim-Altera ASE 10.1d，时钟周期 40 ns，`en=1`、`clr` 先置高再放开：

- 清零后 q=0；
- 每个上升沿加 1，序列 1,2,…,9；
- q=9 时 carry=1；
- 下一个沿 q 回 0，carry 回 0；
- en 拉低后 q 停在 2 不再变化。

输出摘要：

```
t=61000  q=1 carry=0
t=341000 q=8 carry=0
t=381000 q=9 carry=1
t=421000 q=0 carry=0
after disable q=2
```

## 七、结论

同步清零、使能、进位三项行为均与设计要求一致，计数范围可通过参数 N 调整。
