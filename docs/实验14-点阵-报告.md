# 实验十四 LED 16×16 点阵显示

## 一、实验目的

了解 LED 16×16 点阵硬件结构；掌握状态机与串行数据传输设计。

## 二、实验原理

实验箱点阵为 16×16，采用 SPI 式串行接口：SCLK 为时钟、SI 为数据、STR 为锁存。四个 74HC595 级联成 32 位移位寄存器，STR 低电平时串行移入，上升沿并行输出。

一帧数据 32 位：先 16 位行电平，再 16 位列选（低有效）。逐列扫描，每列送一次 32 位。

## 三、设计与实现

- 状态机时钟 60 kHz（48 MHz ÷ 800）。
- 每列：STR 拉低 → 32 个 SCLK 移出数据 → STR 拉高锁存 → 下一列。
- 字模存 ROM，按列取模：4 个汉字共 64 个 16 位字。
- 以 4Hz 步进、按列滚动显示「震撼美味」四字，循环。

```verilog
always @(posedge clk48m) begin
  if (tick) case (phase)
    0: begin str<=0; sclk<=0; bit_cnt<=0; shifter<={row_data, col_sel}; phase<=1; end
    1: begin if (!sclk) begin d_out<=shifter[31]; shifter<={shifter[30:0],1'b0}; sclk<=1; end
             else begin sclk<=0; bit_cnt<=bit_cnt+1; if (bit_cnt==31) phase<=2; end end
    2: begin str<=1; phase<=3; end
    3: begin str<=0; col<=col+1; phase<=0; end
  endcase
end
```

## 四、管脚分配

| 信号 | 管脚 |
|---|---|
| CLK48M | PIN_28 |
| STR | PIN_234 |
| SCLK | PIN_12 |
| D_OUT | PIN_7 |

## 五、编译结果

map / fit / asm 全部通过，0 error；生成 `led1616.sof`（281,522 字节）。逻辑占用 218 cells。

## 六、仿真验证

仿真 3 ms，观察到两帧：

```
STR#0 sclk_in_frame=32 captured=0000FFFE
STR#1 sclk_in_frame=32 captured=3800FFFD
```

每帧 32 个 SCLK；锁存前串行数据为「16 位行数据 + 16 位列选」，第一列 0000/FFFE、第二列 3800/FFFD，与字模「震」的前两列一致。

## 七、结论

串行时序、列扫描与字模读取均正确。字模由 16 像素黑体渲染，笔画的细节（如「撼」）略糊；如需更清晰可换专业 16×16 字模库。显示方式为四字 4Hz 左移滚动，偏移量循环回绕。

## 八、DIY 说明

显示内容自选为「震撼美味」四字，按列滚动；字模由 16 像素黑体渲染后按列取模生成，未使用讲义默认图案。
## 九、滚动显示（P1 补齐）

字模改为 64×16 位 ROM（rom64.hex，四字各 16 列），显示窗口固定 16 列，偏移量每 0.25 秒加一（4Hz），按 (offset+col) mod 64 取列，形成四字循环左移滚动。
