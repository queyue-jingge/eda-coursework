# 实验一 加法器

## 一、实验目的

1. 掌握 Quartus II 的原理图/HDL 输入设计方法。
2. 学会编译、仿真、锁定管脚、下载的完整流程。
3. 掌握半加器与多位全加器的设计方法。

## 二、实验原理

半加器完成两个 1 位二进制数相加，输出本位和 So 与进位 Co：

- So = A ⊕ B
- Co = A · B

真值表：

| A | B | Co | So |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 0 | 1 | 0 | 1 |
| 1 | 0 | 0 | 1 |
| 1 | 1 | 1 | 0 |

## 三、设计与实现

讲义要求用原理图（bdf）输入。本实现用 Verilog 描述同一逻辑，功能等价：

```verilog
module h_adder(input a, input b, output so, output co);
  assign so = a ^ b;
  assign co = a & b;
endmodule
```

器件：EP1C12Q240C8；软件：Quartus II 9.0 SP2 Web Edition。

## 四、管脚分配

| 信号 | 管脚 |
|---|---|
| A | PIN_121 |
| B | PIN_122 |
| CO | PIN_50 |
| SO | PIN_53 |

## 五、编译结果

Analysis & Synthesis、Fitter、Assembler 三步均通过，0 error；生成 `exp1_h_adder.sof`（281,522 字节）。


## 六、仿真验证

半加器为组合逻辑，未单独写 testbench；全加器补了真值表仿真，八组输入结果见第八节。

## 七、全加器（由两个半加器搭成）

讲义步骤 9 要求用半加器封装成全加器。本包另附 `工程文件/全加器` 下的 `full_adder` 工程：

- 第一个半加器算 A+B，得 S1、C1；
- 第二个半加器算 S1+C，得 So、C2；
- Co = C1 | C2。

真值表仿真：000→0、001→1、010→1、011→2、100→1、101→2、110→2、111→3，八种输入全对。

管脚：a=121，b=122，c=124，co=50，so=53；器件 EP1C12Q240C8，sof 281,522 字节。

## 八、结论

半加器逻辑与真值表一致，管脚锁定正确。逻辑过简，未单独仿真；如需验证可加 testbench 遍历四种输入组合。
