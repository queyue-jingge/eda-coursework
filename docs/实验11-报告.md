# 实验十一 数字时钟

## 一、实验目的

掌握计时、进位与多位动态显示。

## 二、实验原理

1 Hz 秒脉冲驱动秒计数，60 进到分、60 进到时、24 进回零；八位数码管扫描显示 HH-MM-SS。

## 三、设计与实现

48M 分频出 1 Hz；秒/分/时计数器；1 kHz 扫描八位，分别取时分秒的十位与个位，第 3、6 位显示横线，七段译码。实验箱按键低有效，顶层已取反：按下 enable 走时，按下 reset 清零。

## 四、管脚分配

clk48M=PIN_28；enable=PIN_121；reset=PIN_122；dig7..0=PIN_214/213/216/215/161/162/159/160；seg0..7=PIN_169/170/167/168/165/166/163/164。

## 五、编译结果

map / fit / asm 全部通过，0 error；生成 digital_clock.sof（281,522 字节）。

## 六、仿真验证

仿真：reset 后 0:0:0；62 个秒脉冲后 0:2:4（仿真强制分频导致倍频，比例正确）；再 3600 个到 2:2:4，进位链正确。

## 七、结论

时、分、秒进位正确，显示扫描可用；可扩展闹钟、秒表。

## 十、八位格式与闪烁（P1 补齐）

显示改为八位 HH-MM-SS：数码 2、5 显示横线，其余为时分秒；最右一位（秒个位）每 0.5 秒灭一次，作走时指示。
