# 实验三 静态数码管显示

## 一、实验目的

1. 了解数码管内部结构（共阴/共阳、段码/位码）。
2. 学习七段译码器设计。
3. 学习使用分频与计数实现 1 Hz 刷新。

## 二、实验原理

实验箱晶振 48 MHz。要得到 1 Hz 的计数节拍，需要对 48 MHz 做 48,000,000 分频，计满翻转一次，得到 0.5 s 高、0.5 s 低的 1 Hz 方波。

计数 0–F 之后，依次显示 H（1 秒）、P（1 秒）、全灭（1 秒），再回到 0，循环。计数结果经七段译码后送段码线；位码全部选通，八个数码管显示同一字符。

实验箱为共阳数码管经三极管驱动：段码低电平点亮，位码低电平选通。

## 三、设计与实现

```verilog
module sled(input clk48m, output [7:0] seg, output [7:0] dig);
  reg [25:0] div;
  reg [4:0] cnt;
  initial begin div = 26'd0; cnt = 5'd0; end
  always @(posedge clk48m) begin
    if (div == 26'd47_999_999) begin
      div <= 26'd0;
      if (cnt == 5'd18) cnt <= 5'd0; else cnt <= cnt + 1'b1;
    end else div <= div + 1'b1;
  end
  assign dig = 8'h00;
  assign seg = (cnt == 5'd16) ? 8'b1000_1001 :   // H
               (cnt == 5'd17) ? 8'b1000_1100 :   // P
               (cnt == 5'd18) ? 8'b1111_1111 :   // 全灭
               decode(cnt[3:0]);
  // decode: 共阳低有效七段码，0-F
endmodule
```

译码表（dp g f e d c b a，低有效）：

| 字符 | 段码 | 字符 | 段码 |
|---|---|---|---|
| 0 | 1100_0000 | 8 | 1000_0000 |
| 1 | 1111_1001 | 9 | 1001_0000 |
| 2 | 1010_0100 | A | 1000_1000 |
| 3 | 1011_0000 | B | 1000_0011 |
| 4 | 1001_1001 | C | 1100_0110 |
| 5 | 1001_0010 | D | 1010_0001 |
| 6 | 1000_0010 | E | 1000_0110 |
| 7 | 1111_1000 | F | 1000_1110 |

## 五、编译结果

map / fit / asm 全部通过，0 error；生成 `sled.sof`（281,522 字节）。

## 六、仿真验证

ModelSim 中把分频计数器强制到 47,999,999 以跳过 48M 次计数，观察计数与译码：

```
cnt=1 seg=11111001
cnt=3 seg=10110000
cnt=5 seg=10010010
cnt=7 seg=11111000
cnt=9 seg=10010000
cnt=b seg=10000011
cnt=d seg=10100001
cnt=f seg=10001110
```

各计数对应的段码与译码表一致。仿真中因强制赋值每周期触发两次，显示为奇数序列，属 testbench 手法所致，不影响设计。

## 七、结论

分频、计数、译码三部分均正确，静态显示链路可用。下一步（实验四）在此译码基础上增加位码扫描。
