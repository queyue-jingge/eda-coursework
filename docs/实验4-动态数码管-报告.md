# 实验四 动态数码管显示

## 一、实验目的

1. 理解动态扫描显示原理。
2. 掌握位码扫描与段码切换的配合。
3. 在实验三译码基础上实现八位数码管显示不同字符。

## 二、实验原理

各数码管段码并联、位码独立。任一时刻只选通一位，同时送出该位应显示的段码，依次快速轮换，利用视觉暂留形成稳定显示。

刷新频率：扫描计数器每 65,536 个 48 MHz 时钟切换一位，则每位刷新率约 48 MHz / 65,536 ≈ 732 Hz，八位一轮约 91 Hz，满足人眼不闪烁且亮度足够的要求。

位码低电平选通（共阳经三极管驱动），八位轮流为低。

## 三、设计与实现

```verilog
module dled(input clk48m, input key1, output [7:0] seg, output [7:0] dig);
  reg [15:0] div; reg [2:0] sel;
  always @(posedge clk48m) begin
    div <= div + 1'b1;
    if (div == 16'hFFFF) sel <= sel + 1'b1;
  end

  reg k0, k1;
  always @(posedge clk48m) begin k0 <= key1; k1 <= k0; end
  wire blank_last = ~k1;          // 按键低有效

  reg [3:0] d; reg off;
  always @(*) begin
    off = 0;
    case (sel)
      3'd0: begin d = 4'h6; if (blank_last) off = 1; end
      3'd1: d = 4'h5;
      3'd2: d = 4'h4;
      3'd3: d = 4'h3;
      3'd4: d = 4'h2;
      3'd5: d = 4'h1;
      default: begin d = 4'h0; off = 1; end   // 左两位灭
    endcase
  end

  assign dig = ~(8'h01 << sel);
  assign seg = off ? 8'b1111_1111 : decode(d);
endmodule
```

左两位灭，右六位显示 123456；K1（PIN_121）按下时最右一位灭，其余位不受影响。

## 五、编译结果

map / fit / asm 全部通过，0 error；生成 `dled.sof`（281,522 字节）。

## 六、仿真验证

自然计数下观察十次位码切换：

```
sel=0 dig=11111110 seg=10000010   (显示 6)
sel=1 dig=11111101 seg=10010010   (显示 5)
sel=2 dig=11111011 seg=10011001   (显示 4)
sel=3 dig=11110111 seg=10110000   (显示 3)
sel=4 dig=11101111 seg=10100100   (显示 2)
sel=5 dig=11011111 seg=11111001   (显示 1)
sel=6 dig=10111111 seg=11111111   (灭)
sel=7 dig=01111111 seg=11111111   (灭)
K1 按下: sel=0 dig=11111110 seg=11111111   (最右位灭)
```

位码按 11111110 → 01111111 顺序循环，每次只有一位为低；段码与该位待显示数字一致，循环顺序正确。

## 七、结论

扫描显示工作正常，位码与段码时序对应，刷新率约 732 Hz/位；仿真见六位 123456 与 K1 灭位。

## 八、六位显示与灭位（P1 补齐）

左两位灭，右六位显示 123456；K1（PIN_121）按下时最右一位灭。扫描仍为 8 位动态。
