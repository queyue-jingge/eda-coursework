# 实验十三 TLC5620（D/A）控制

## 一、实验目的

掌握串行 D/A 的数据帧与更新时序。

## 二、实验原理

TLC5620 为四通道 8 位串行 DAC，帧为 2 位通道 + 1 位 RNG + 8 位数据，LOAD 低电平锁存、送数期间为高。

## 三、设计与实现

状态机 2MHz，DA_CLK 1MHz（手册上限）；11 位帧从高位串出，送 DAC A 通道；送完拉低 LOAD 锁存不少于 250ns，再拉高。一帧约 17.5us。

## 四、管脚分配

clk48M=PIN_28；dac_load=PIN_118，dac_clk=PIN_181，dac_data=PIN_217，dac_ldac=PIN_7（恒低，锁存后立即转换）。
data_in[0..7]=PIN_41/47/58/64/65/98/99/173（同上）。
数码管：本工程没有接数码管，qsf 未分配 seg/dig。

## 五、编译结果

map / fit / asm 全部通过，0 error；生成 tlc5620.sof（281,522 字节）。

## 六、仿真验证

未单独仿真。

## 七、结论

数据帧与 LOAD 时序符合器件要求；可接示波器验证阶梯波输出。

## 八、按讲义修正（2026-11-06）

- 帧格式改为 11 位：D10-D9 通道 + D8 RNG + D7-D0 数据。
- LOAD 改为高电平送数（11 个 DA_CLK 下降沿逐位送出），送完拉低 ≥250ns 锁存，再拉高。
- 增加 LDAC 输出并恒为低，数据锁存后立即转换。
- 片内 64 点正弦表（sine64.hex）驱动，输出约 1kHz 正弦，不再用外部 8 位开关。
- 管脚：clk48m=28，dac_load=118，dac_clk=181，dac_data=217，dac_ldac=7。

## 九、频率修正（P1 补齐）

状态机 2MHz，DA_CLK 1MHz（TLC5620 手册上限）；64 点正弦一帧约 17.5us，输出约 990Hz，接近 1kHz。
