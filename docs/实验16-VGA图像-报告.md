# 实验十六 VGA 图像静态显示

## 一、实验目的

掌握用 ROM 存储像素并扫描显示图像的方法；理解分辨率、色深与存储容量的关系。

## 二、实验原理

VGA 时序与实验十五相同（640×480、行 800、场 525、负极性同步）。

图像数据存 ROM，按扫描坐标取像素。存储量 = 宽 × 高 × 色深。本设计取 128×64、8 位色，共 8192 字节（65,536 位）。

## 三、设计与实现

- 原图缩放到 128×64、8 位色（RRRGGGBB），存 `miku64.hex`。
- 像素节拍用 48MHz 门控等效 25MHz（每 48 个时钟放行 25 个），场频约 59.5Hz；未使用 ALTPLL，属等效实现，时序有 ±1 周期抖动。
- 显示映射：x = hcnt/5（横向 5 倍），y = (vcnt×64)/480（纵向 7.5 倍），addr = y×128 + x。
- 地址与像素各打一拍；行首两个预取像素已屏蔽，避免读到上一行末尾。

```verilog
wire [15:0] yv = (vcnt * 16'd64) / 16'd480;
wire [6:0] y = yv[6:0];
wire [13:0] addr = {y, 7'b0} + x;
reg [13:0] addr_r; always @(posedge clk48m) if (en25) addr_r <= addr;
reg [7:0] rom [0:8191];
initial $readmemh("miku64.hex", rom);
reg [7:0] pix; always @(posedge clk48m) if (en25) pix <= rom[addr_r];
```

## 四、管脚分配

HS=PIN_17，VS=PIN_15，RGB7..0=PIN_45/43/41/23/20/18/16/14，CLK48M=PIN_28。

## 五、编译结果

map / fit / asm 全部通过，0 error；生成 `vga_image.sof`（281,522 字节）。ROM 推断为 16 个 M4K、65,536 位；逻辑约 256 个 LE。

## 六、仿真验证

抽点比对（与 `miku64.hex` 对应地址一致）：

```
h=0   v=0   -> 00
h=10  v=10  -> C0
h=320 v=240 -> 12
h=635 v=475 -> 0E
```

纵向映射修正后，v=0/240/475 分别落在第 0、32、63 行，不再全部压到第 0 行。

## 七、结论

图像能从 ROM 正确读出并按 5×7.5 放大显示。受片内 RAM 限制，128×64 拉到 640×480 呈马赛克；25MHz 为门控等效，若要严格 PLL 需在 Quartus 图形向导中生成 altpll。

## 八、DIY 说明

显示图片为自选的同人插画，裁成 2:1 后缩放到 128×64、量化到 8 位色，未使用讲义占位图案。

## 九、25MHz 与 128×64（P1 补齐）

- 像素节拍改为 48MHz 门控等效 25MHz（每 48 个时钟放行 25 个），替代原来的二分频 24MHz；未使用 ALTPLL。
- ROM 改为 128×64（8192 字），横向 5 倍、纵向 7.5 倍映射，修正原来只覆盖 120 行导致的底部裁行。
